# PRINCE2 7 Governance Mapping

## Mapping Table

| Hybrid Element | PRINCE2 7 Equivalent | Purpose / Relationship |
|----------------|----------------------|------------------------|
| Sponsor | Project Board (Executive) | Ultimate decision maker and business justification owner |
| Project Manager | Project Manager | Overall management of stage boundaries, tolerances, and governance |
| Product Owner | Senior User | Represents user interests and specifies feature requirements |
| Developers | Team Manager / Developer | Delivers work packages according to technical specifications |
| Phase Gate (G1–G4) | End Stage Assessment | Formal board review to evaluate stage progress and approve next stage |
| Sprints 1–4 | Management Stage / Work Packages | Structured iteration cycles delivering agreed work packages |
| Backlog Item | Product Description | Detailed specification of deliverables and quality criteria |
| Definition of Done | Quality Criteria & Quality Register | Quality benchmarks required for product acceptance |
| Weekly Highlight Report | Highlight Report | Periodic progress update sent to the Project Board |
| Tolerance Breach | Exception Report | Escalation trigger when time/cost/scope constraints are exceeded |
| G4 Acceptance & Closure | Closing a Project (CP) | Formal project handover and end-of-project evaluation |

## What PRINCE2 Adds
PRINCE2 introduces formal **Continued Business Justification** through a explicit Business Case that is re-validated at every stage gate (End Stage Assessment). It adds structured **Work Package Management** with formal agreements between the PM and Team Managers, ensuring strict risk and issue management protocols beyond informal daily scrums.

## What PRINCE2 Makes Heavier
PRINCE2 adds significant administrative documentation overhead. Requiring formal Stage Plan approvals, formal Exception Reports, and detailed Product Descriptions for every increment adds reporting friction that can slow down a small 4-student project team working within tight 2-week agile sprints.
